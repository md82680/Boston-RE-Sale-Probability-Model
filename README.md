# Real Estate Sale Probability Predictor

A full-stack application that predicts the likelihood of a property selling based on various features.

## Project Structure

- **Frontend**: React application with TypeScript and Tailwind CSS
- **Backend**: FastAPI application with machine learning model for predictions

## Getting Started

### Prerequisites
- Node.js 14+
- Python 3.8+
- pip
