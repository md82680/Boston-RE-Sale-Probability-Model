# Boston Real Estate Sale Probability Predictor

## Overview
A full-stack application that predicts the likelihood of real estate properties selling in Boston. The system combines a machine learning backend with a responsive React frontend to provide real-time property sale predictions and batch processing capabilities.

## Project Structure
```
├── backend/           # FastAPI and ML model backend
│   ├── api/          # API implementation
│   ├── models/       # Trained ML models
│   ├── src/          # Source code
│   └── README.md     # Backend documentation
├── frontend/         # React TypeScript frontend
│   ├── src/         # Frontend source code
│   ├── public/      # Static assets
│   └── README.md    # Frontend documentation
└── README.md        # Main project documentation
```

## Features
- Machine learning model for property sale predictions
- Real-time prediction API
- Batch processing for multiple properties
- Interactive web interface
- CSV export functionality
- Performance monitoring and analytics

## Quick Start

### Backend Setup
```bash
cd backend
conda create -n real-estate-project python=3.12
conda activate real-estate-project
pip install -r requirements.txt
uvicorn api.main:app --reload
```

### Frontend Setup
```bash
cd frontend
npm install
npm start
```

The application will be available at:
- Frontend: http://localhost:3000
- Backend API: http://localhost:8000
- API Documentation: http://localhost:8000/docs

## Docker & Kubernetes Setup

### Local Development with Docker
The application is containerized using Docker for consistent development environments:

- **Backend Container**: FastAPI application serving ML predictions
  ```bash
  # Build and run backend only
  docker-compose up backend
  ```

- **Frontend Container**: React application served via Nginx
  ```bash
  # Build and run frontend only
  docker-compose up frontend
  ```

- **Full Stack Development**:
  ```bash
  # Build and run all services
  docker-compose up --build
  ```

### Kubernetes Deployment
The application is configured for cloud deployment using Kubernetes:

- **Deployment Configuration**: `k8s/deployment.yaml`
  - Frontend and Backend services
  - Load balancer configuration
  - Service definitions

- **Auto-scaling Configuration**:
  ```yaml
  apiVersion: autoscaling/v2
  kind: HorizontalPodAutoscaler
  metadata:
    name: real-estate-predictor-hpa
  spec:
    minReplicas: 1
    maxReplicas: 10
    metrics:
    - type: Resource
      resource:
        name: cpu
        target:
          type: Utilization
          averageUtilization: 80
  ```

### Development Commands
Using Make for simplified commands:
```bash
# Local Development
make start-all          # Run frontend & backend locally
make start-frontend     # Run frontend only
make start-backend      # Run backend only

# Docker Development
make docker-up          # Start Docker containers
make docker-build       # Rebuild and start containers
make docker-down        # Stop containers

# Testing
make test-frontend      # Run frontend tests
make test-backend      # Run backend tests
```

## Deployment Notes
1. The HorizontalPodAutoscaler (HPA) automatically scales replicas based on CPU utilization
2. Kubernetes manages load balancing across replicas
3. Configuration supports scaling from 1 to 10 replicas based on demand
4. Frontend served via Nginx for optimal performance
